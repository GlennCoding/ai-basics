# How to calculate the slope (in a 2D space)

left: 6 -> f(6) = 14
right: 8 -> f(8) = 30

Actual distance between left & right = 30-14 = 16
Distance between x vales of left and right = 2
Slope = 16 / 2 = 8

Simplified:
slope = (f(x + h) - f(x - h)) / (2 * h)
